# Home Credit LAP Voice Agent

## About the Project

I built this voice agent using Retell AI as part of my AI assignment. The idea was to create an agent that can talk to customers and check whether they meet the basic requirements for a Loan Against Property (LAP).

The agent asks questions about the customer's property, ownership, documents, income, loan amount, property value, and preferred loan tenure. Based on the answers, it decides whether to continue the eligibility process or end the call.

## What It Can Do

- Talk to customers in a natural way.
- Ask questions to check basic loan eligibility.
- Identify cases that do not meet the requirements.
- Stop the process if the property is agricultural or the required documents are unavailable.
- Check whether income is received through a bank account.
- Refer customers with an existing property loan to a loan-transfer specialist.
- Inform eligible customers about the next steps.

## Test Cases

I tested the agent with these five situations:

1. A customer who meets the basic eligibility requirements.
2. A customer with agricultural property.
3. A customer who mainly receives income in cash.
4. A customer who does not have the original property documents.
5. A customer who wants to transfer an existing loan.

## Tools Used

- Retell AI
- Prompt Engineering
- AI Voice Agent Testing

## Note

This agent only checks preliminary eligibility. Final loan approval depends on document verification and the lender's decision.
